These results support saying our generation speed is broadly consistent with the published CPU benchmarks. They do not prove identical performance: hardware, prompt lengths, output lengths, and cache conditions differ.

The repository also reports roughly two minutes to process a 500-token prompt from a cold cache. Slow initial prompt processing is therefore a limitation acknowledged by the project itself.

Two caches, two different jobs

Expert cache: keeps model expert weights in RAM so the server needs fewer storage reads.

KV cache: stores attention information for processed tokens. If the engine supports and successfully matches a reusable prompt prefix, later requests can avoid some repeated computation.

A warm expert cache does not automatically mean prompt tokens were reused. The 117-second example reported zero reused prompt tokens.
